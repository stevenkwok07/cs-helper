# CS Helper

Tampermonkey userscript: CS Inbox Helper + Sapaan + Auto Reply (LiveChat & Text).

**Install:** buka https://raw.githubusercontent.com/stevenkwok07/cs-helper/main/cs-helper.user.js lalu klik Install di Tampermonkey.

**Revisi:** edit `cs-helper.user.js`, naikin `@version`, commit. Semua komputer tinggal klik tombol Update (tanpa refresh).
